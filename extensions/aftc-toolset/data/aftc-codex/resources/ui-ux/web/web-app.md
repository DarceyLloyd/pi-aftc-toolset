# Web App Design

*Scope: VISUAL design of web APPLICATIONS (SPA, dashboard, app-like stateful flows in the
browser). Never API/backend mechanics. For content/marketing pages see web-page.md; for
admin/back-office web UIs see web-backend.md; for desktop shells see desktop-web-app.md /
desktop-app.md.*

## Rules

- [9yqbTu] Browse state users expect restored on browser back/forward (active filters, expanded accordion branches, search text) but reset on a fresh visit belongs in an IN-MEMORY app store, never localStorage - localStorage resurrection on a new visit surprises users, and in-memory dies exactly when it should.
