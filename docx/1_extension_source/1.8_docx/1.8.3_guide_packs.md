## prompts/ — the 10 type packs

Each pack names its family's sources of truth, surface-inventory rules
and per-surface contract specifics; family-generalised, never grown back
into an all-in-one:

| Key | Covers |
| --- | --- |
| `web-app` | PHP/Apache/MySQL/Docker, MVC backends, Angular/React/Next/Vue + custom TS/JS frontends |
| `basic-website` | static HTML/CSS/JS |
| `webgpu-webgl` | Three.js / Babylon |
| `desktop-app` | Electron, .NET, Java, Qt |
| `juce-vst` | C++ JUCE audio plugins |
| `mobile-app` | mobile stacks |
| `python-app` | Python applications |
| `cli-tool` | CLI/TUI tools (commands as pages, wizards, key maps) |
| `shell-scripts` | bash/sh/ps1/bat collections |
| `generic` | closest-match fallback |

Maintainer rule: platform-neutral rules belong in the guide's core, never
duplicated into packs.

## Runtime states

- Detection matched: the matching pack is pre-selected in the picker.
- No detection: picker without pre-select; headless without `--type`
  refuses and lists the keys.
- Unknown `--type` value: refused with the key list.
- Missing guide or pack file at run time: prompt assembly fails → error
  line, nothing generated.
