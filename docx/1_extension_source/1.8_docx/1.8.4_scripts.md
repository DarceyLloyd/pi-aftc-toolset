## Function

Four plain-Node `.mjs` helpers the model runs mid-generation/mid-update
(paths are substituted into the injected prompt by docx.ts). All
self-terminating.

| Script | Role |
| --- | --- |
| `map-scan.mjs` | Step-1 reconnaissance: directory tree (exclusions honoured), manifest inventory with dependency versions, containers (compose services + Dockerfiles), test surfaces, CI files, and UI surface hints (template/declarative surface files + surface-named source files — capped, "verify against source, never proof"). Output is recon INPUT, not truth. |
| `link-audit.mjs` | Step-11 mechanical audit: every `](…md)` link resolves across the nested tree; `./docx/…md` prose refs exist; stamps match `YYYY-MM-DD HH:MM`; ID-prefixed files' H1 starts with their ID; every map ID has exactly one doc; docx/ mirrors the map (ID folders, ancestry chains, folder per node-with-children); every doc has References + Related; sitemaps carry HIGH LEVEL + LOW LEVEL; page leaves carry States; every generated doc appears in the master's index; every UI-hint file is referenced by at least one doc. Prints PASS or a failure list. |
| `ui-hints.mjs` | The UI-surface hint collector used by map-scan (shared logic). |
| `zip-old.mjs` | FINAL step (both commands): `zip-old.mjs <root> <label>` packs `./docx/old_docs/` (adm-zip) into a TIMESTAMPED zip inside `./docx/backups/` — label `original` (/docx) -> "Original Documentation Backup YYMMDD HHMM.zip", label `update` (/docx-update) -> "Documentation Backup YYMMDD HHMM.zip" — verifies the zip entry count against disk, then deletes `old_docs/` so future sessions never read superseded docs. `backups/` accumulates across runs; a zip entry-count mismatch exits 1 and keeps `old_docs/`. |

## Invocation (copy-pasteable)

```bash
node extensions/aftc-toolset/docx/scripts/map-scan.mjs <projectRoot>
node extensions/aftc-toolset/docx/scripts/link-audit.mjs <projectRoot>
node extensions/aftc-toolset/docx/scripts/zip-old.mjs <projectRoot> original   # /docx
node extensions/aftc-toolset/docx/scripts/zip-old.mjs <projectRoot> update     # /docx-update
```

## Runtime states

- Audit failures → non-zero exit + itemised report; the run fixes and
  re-runs until PASS.
- zip-old with no old_docs folder → no-op success; with an EMPTY
  old_docs folder → removes it without creating a zip; unknown label →
  exit 1 naming the valid labels.
