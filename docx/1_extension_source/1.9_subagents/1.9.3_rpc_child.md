ONE supervised `pi --mode rpc` child process + the custom strict-LF
JSONL reader. Why not pi's shipped RpcClient (verified against dist):
stderr echoed to the parent TTY, no `detached` (no killable group),
racy 100ms readiness sleep, relative `dist/cli.js` default.

- `SubAgentJsonLineReader` — invariant 11: splits on `\n` BYTES only
  (Node readline splits on U+2028/U+2029), strips one trailing `\r`,
  decodes UTF-8 only for complete lines (split multibyte survives).
  Malformed lines reported + skipped, never fatal.
- `resolvePiEntry()` — prefer the parent's own entry
  (`process.argv[1]` under `process.execPath`); PATH fallback
  (`pi`/`pi.cmd`). Never hardcode `dist/cli.js`.
- `buildSubAgentChildArgs(spec)` — `--mode rpc`, `--no-extensions` +
  one `-e child-runtime.ts`, `--no-prompt-templates --no-themes
  --no-skills --no-approve`, resolved `--model` (+`--thinking`),
  `--tools` comma allowlist (EMPTY tools = omit the flag entirely —
  an empty allowlist would strip every built-in; when present,
  `report_result` is always appended because the flag filters
  extension tools too), `--skill` paths, `--no-context-files` only for
  `context_files: none`, `--session-dir` or `--no-session`.
- `killSubAgentProcessTree(pid, force)` — POSIX: signal the negative
  pid; Windows: `taskkill /pid <pid> /T [/F]`. Never throws.
- `spawnSubAgentChild(options)` — detached, `windowsHide`, env
  scrubbed of every `PI_SESSION_*`; id-less response ACKs are
  SWALLOWED (never routed as events — they would fake watchdog
  progress). Handle: `pid`, `exited`, `sendCommand`, `request`
  (id-correlated + timeout; readiness is a real `get_state` request —
  a SIGNAL, never a sleep), `closeStdin`, `killTree`, `dispose`.
  Test seam: `entryOverride` (the fake-child harness).

## Transport states

Ready-handshake timeout, child crash mid-run and abort all end in
`killTree` + `dispose` (no process tree survives); strict-LF framing
rejects partial/CRLF lines; the fake-child harness drives every hostile
scenario through the `entryOverride` test seam.
