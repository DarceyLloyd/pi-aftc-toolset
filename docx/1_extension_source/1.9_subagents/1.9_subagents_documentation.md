## Purpose

Delegate focused work to isolated child pi processes (sub-agents),
each with its OWN fresh context window, profile-owned capabilities and
a bounded report back. The parent model stays the planner; the
extension coordinates. Foreground-only in v1 (Phase 0 -> 1 of
the design): one `subagent` tool call = one run; parallelism comes
from sibling tool calls.

Owns `extensions/aftc-toolset/subagents/` (9 modules + readmes) and
the shipped seed `extensions/aftc-toolset/data/subagents/` (9 built-in
sub-agent `.md` files + the user guide `README.md` — DATA ONLY, no
code in the seed). Does NOT own the footer widget (1.4) — it consumes
a line callback; does NOT write to `turns.db` (spend is in-memory).

## Non-negotiable rules

- **Disabled by default.** `enabled: false` in `<dataDir>/
  subagents-config.json`; `/007` option 1 enables — confirm ONLY when
  the live data dir is missing ('Unable to detect local sub agents
  data directory. Shall I create and seed?', Yes/No), seed the agents
  folder, flip on. A seed failure ABORTS the enable.
- **Capabilities live in the PROFILE, never in tool arguments.** The
  `subagent` schema is exactly `agent/task/context/acceptance/
  target` — NO mode field (v1 foreground-only), no model/tools/timeout
  /budget (design invariant 8).
- **Fresh context by default** — children see the briefing only.
- **Model resolved BEFORE spawn** (inherit / exact / fuzzy / fallback
  array via `ctx.modelRegistry`) — never fail after spawn.
- **Children are hermetic** (design section 11): `--no-extensions` +
  exactly one `-e child-runtime.ts`, `--no-approve`, scrubbed
  `PI_SESSION_*` env. Only exposable capability: read-only aftc-codex
  (`codex_load` + topic brief), triple-gated by parent codex enabled
  AND `codexAccessEnabled` AND the sub-agent's `codex` flag. Codex
  writes are parsed but read-only enforced in v1. Notifications, usage
  DB, docx, SSH and UI are NEVER exposed.
- **No database writes** — session spend lives in the supervisor's
  in-memory accumulator. Spending guard = the allowance gate
  (1.4's `AllowanceProvider`), not a cost gate.
- **No orphaned trees** — detached spawn, termination ladder (abort ->
  wait settled -> close stdin -> wait exit -> SIGTERM group -> SIGKILL
  group / `taskkill /T /F`), session_shutdown force-kill, module-level
  process `exit` hook (abnormal-parent net).
- **No command aliases** — `/007` + `/007-*` only (pi silently
  suffixes colliding names).
- Naming: capital-A `SubAgent` prefix; config keys UNPREFIXED inside
  `subagents-config.json`.

## Command surface

`/007` (main menu) · `/007-status` (live table) · `/007-kill`
(multi-select kill) · `/007-edit [name]` ·
`/007-reset <name>` · `/007-install` (seed) · `/007-sync`
(non-destructive merge) · `/007-open-agent-dir` · `/007-guide` ·
`/007-settings` · `/007-doctor`. All menus via aftc-ui
(Action -> Manage -> Configure -> Help; Enabled/Disabled vocabulary);
all output via aftc-console; headless falls back to bounded
`aftcConsole.print` blocks.

## Storage

```
<dataDir>/subagents-config.json            # feature config (own file)
<dataDir>/subagents/
  agents/*.md                              # live agents (seeded, editable)
  agents/README.md                         # user guide (skipped by discovery)
  agents/.subagents-seed-manifest.json     # seed hashes + seed version
  runs/<run-id>/                           # meta.json, run-config.json (0600),
                                           # transcript.jsonl, report.json
<package>/extensions/aftc-toolset/data/subagents/
  agents/*.md + README.md                  # pristine shipped seed
  (data/extension-config.json: subagentsSeedVersion = 6)
```

Seed-to-live mirrors aftc-codex: idempotent copy-only, never overwrite;
`/007-sync` updates untouched files via the manifest hashes and reports
user-edited files as conflicts; `subagentsSeedVersion` mismatch shows a
menu notice.

`subagents-invariants-check/` (60s — invariants 10/13/19),

invariant 18). Token-free; every script self-terminates with a global
watchdog.
