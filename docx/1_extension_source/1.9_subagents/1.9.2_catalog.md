Discovery + parsing + resolution of sub-agent profiles (markdown with
YAML frontmatter), plus the seed-to-live machinery.

## Tiers (no silent shadowing)

| Tier | Location | Note |
| --- | --- | --- |
| project | `<cwd>/.pi/agents/*.md` | gated until the Phase-3 approval lands (`includeProject`) |
| user | `<dataDir>/subagents/agents/` + `<piAgentDir>/agent/agents/` | `PI_CODING_AGENT_DIR` replaces `~/.pi` |
| builtin | package seed dir | pristine, never edited |

Discovery keeps ALL copies: unqualified names resolve by tier
precedence (the seeded live copy is authoritative over the pristine
package copy); qualified ids (`user/explorer`, `builtin/explorer`) reach a
specific tier. Skips `README.md` + `_*.md`; `enabled: false` hides
(unless `includeDisabled` — the `/007-edit` picker, so a disabled
agent can be re-enabled from inside pi);
`disableDefaultAgents` hides the built-in roster. Leading `@` stripped.

## Frontmatter

Every design-6.1 field with its default — identity, brains (`model`
id/fuzzy/`inherit`/fallback array, `model_tier`, `thinking`),
capabilities (`tools`, `disallowed_tools`, `skills`, `codex`,
`codex_write`), limits (`max_turns`, `timeout_seconds`,
`stall_timeout_seconds`, `stall_detection`, `loop_detection`),
behaviour (`context_files`, `prompt_mode`, `inherit_context`,
`persist_session`, `output_transcript`, `enabled`, `tags`, `extends`).
`extends:` chains inherit frontmatter + body with override (memoised,
depth-capped 5, cycle-safe). Frontmatter is authoritative (invariant 8).

## Seed-to-live (codex pattern)

- `seedSubAgentBuiltIns()` — idempotent copy-only (never overwrites);
  seeds the agents + the `README.md` guide; records
  `.subagents-seed-manifest.json` (file -> sha256 + seed version).
  Throws on failure so the `/007` enable flow aborts.
- `syncSubAgentBuiltIns()` — `/007-sync`: live files matching their
  manifest hash update to the new shipped version; user-edited files
  are reported as conflicts and left untouched; missing files added.
- `resetSubAgentBuiltIn(name)` — `/007-reset`.
- `getShippedSubAgentsSeedVersion()` reads
  `data/extension-config.json: subagentsSeedVersion`;
  `subAgentSeedMismatch()` drives the menu notice.

## Catalog & sync states

No live agents dir → the built-in tier still resolves (enable flow seeds
first); disabled agents are hidden unless `includeDisabled` (the
`/007-edit` picker); `disableDefaultAgents` hides the built-in roster;
sync leaves user-edited files as reported conflicts, adds missing files.
