## Commands (NO aliases — design Q3)

`/007` main menu · `/007-status` live table · `/007-kill` multi-select
(or single id, headless-safe) · `/007-edit
[name]` (picker when no name; On/Off options menu for the boolean
frontmatter flags — codex, codex_write, stall/loop detection, output
transcript, persist session, enabled — plus raw-file edit and reset;
built-ins are synced to a live copy first) · `/007-reset
<name>` (confirm) · `/007-install` · `/007-sync` · `/007-open-agent-dir`
(seeds if empty; `explorer.exe`/`open`/`xdg-open` detached + unref;
always prints the path) · `/007-guide` · `/007-settings` ·
`/007-doctor`. Every command gets its `registerHelpEntry` row —
category `Sub-agents`.

## UI standards (every screen)

aftc-ui ONLY (`showMenu`/`showConfirm`/`showInput`/`showIntInput`/
`showViewer`) + aftc-console output; `ctx.hasUI` guards; headless
prints bounded blocks (`printSubAgentSummary`/`printSubAgentStatus`).
Grouping Action -> Manage -> Configure -> Help; verb-led labels;
Enabled/Disabled vocabulary (enums show their value — no tri-states);
live counts in parens; Esc = back; destructive actions confirm.

## Key screens

- **Disabled main menu** (the default): option 1 **Enable sub-agents**
  -> confirm ONLY when the live data dir is missing ('Unable to detect
  local sub agents data directory. Shall I create and seed?', Yes/No)
  -> `seedSubAgentBuiltIns()` -> `enabled: true`. A seed
  failure ABORTS via `aftcConsole.error` — never half-seed into ON.
- **Enabled main menu**: Active work row (hidden when idle), Browse
  agents (source dots ▪/◦/•; detail actions View/Edit/Eject/
  Disable/Delete/Reset-to-default), Open agents folder, seed-mismatch
  notice row (-> `/007-sync`), Settings, Read the guide, Disable
  (runs active => finish-or-kill prompt), Help.
- **Settings**: Feature toggle (seed-guarded), presets, capacity
  numbers, safety toggles + thresholds, Output toggles — all via
  `setSubAgentPref`/`setSubAgentPreset`.
- **Status**: `buildSubAgentStatusLines` table (id/agent/state/
  elapsed/ctx% with `(cN)`/tokens/tools + session spend).
- **Kill**: toggle-mark rows, `(all N active)`, confirms, each through
  the full termination ladder.
- **Doctor**: pi entry, transport, feature state, catalog health, seed
  version, watchdog-trip counts, no-DB-write note.

Deferred: `/007-fleet`, `/007-stop`, `/007-new`, `/007-preview`,
`/007-packs` (phases 2+).

## Menu states

Two menu states: the DISABLED main menu (the default — enable-first,
seed-guarded confirm) and the ENABLED main menu (active-work row hidden
when idle, seed-mismatch notice row when the shipped seed moved on).
Disable with runs active → finish-or-kill prompt. Headless prints
bounded blocks instead of overlays; Esc = back everywhere.
