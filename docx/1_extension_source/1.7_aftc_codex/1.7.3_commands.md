## Function

The user surface of aftc-codex: 12 slash commands (each `/aftc-codex-*`
with a `/codex-*` alias) and the settings menus. Source:
`codex-commands.ts` (646 lines). Menu handlers are TUI-only (headless:
"use the /aftc-codex-* commands, try /aftc-codex-status"). Every
destructive/menu entry path passes the compat guard first (1.7.1).

## Commands

| Command (alias) | Behaviour |
| --- | --- |
| `/aftc-codex` (`/codex`) | Open the config MENU (below) |
| `/aftc-codex-enable` (`/codex-enable`) | Enable; first enable runs the seed choice flow |
| `/aftc-codex-disable` (`/codex-disable`) | Disable + strip from context; reports when already disabled |
| `/aftc-codex-init` (`/codex-init`) | Prep the session: load rules + fetch relevant docs for this project (refuses in rules-only mode) |
| `/aftc-codex-refresh` (`/codex-refresh`) | Strip all codex, then re-init (clean restart) |
| `/aftc-codex-learn` (`/codex-learn`) | Record durable lessons (1.7.5) |
| `/aftc-codex-status` (`/codex-status`) | Viewer: enabled/prepped state, resource counts, Codex version row (not installed / up to date / update available + the fix command) |
| `/aftc-codex-install` (`/codex-install`) | Wipe + fresh re-seed. Confirmation ONLY when live version == shipped version (a mismatch already sent you here, so typing is the confirmation; headless included) |
| `/aftc-codex-sync` (`/codex-sync`) | Non-destructive update: merge new shipped resources into the live codex (learned entries kept); success message adapts to state (disabled → /codex-enable, prepped → /codex-refresh, else /codex-init) |
| `/codex-inject-rules` | Session-only rules-only mode (1.7.2) |
| `/codex-live-to-seed [--apply]` | MAINTAINER, dev-gated by the `.dev` marker folder: port live codex entries into the package seed (1.7.5) |

## Screen: /codex main menu (surface)

`showMenu`, title "Menu:", body `AFTC Codex: <N> resources available` +
`Session state: Prepped / Not prepped (Run /codex-init to prep the AI) /
Rules-only`. Rows (labelWidth 34, settings-hub convention): `Codex
Enabled | Yes/No` · `Inject Thought Guidance | Yes/No` · `Auto-Detect &
Load Docs | Yes/No` · `Auto Sync Codex Update on Startup | Yes/No` ·
`Resources & Updates` (sub-menu: sync / install / status). Enter flips
toggles and re-renders (selection preserved); Esc closes. Enabling from
the menu triggers the seed choice first.

## Screen: seed choice (surface)

First enable: Pre-trained (Recommended) — rules + ~27 topic docs · Fresh
Start — rules + guidance only. Cancel → "Seed cancelled — AFTC Codex left
disabled." The install menu offers `Start Fresh — Wipe users codex files
and start fresh`.

## Runtime states

- Headless menu attempts → guidance line pointing at the status command.
- Compat unsafe → guard screen (clean choice between /codex-sync and
  /codex-install) before any menu/command proceeds.
