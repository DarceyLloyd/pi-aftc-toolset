## Function

The user surface of aftc-codex: 11 slash commands (10 `/aftc-codex-*`
each with a `/codex-*` alias, plus the standalone `/codex-inject-rules`)
and the settings menus. Source: `codex-commands.ts`. Menu handlers are
TUI-only (headless: "use the /aftc-codex-* commands, try
/aftc-codex-status").

## Commands

| Command (alias) | Behaviour |
| --- | --- |
| `/aftc-codex` (`/codex`) | Open the config MENU (below) |
| `/aftc-codex-enable` (`/codex-enable`) | Enable; first enable copies the shipped rules + guidance |
| `/aftc-codex-disable` (`/codex-disable`) | Disable + strip from context; reports when already disabled |
| `/aftc-codex-init` (`/codex-init`) | Prep the session: load rules + fetch relevant docs for this project (refuses in rules-only mode) |
| `/aftc-codex-refresh` (`/codex-refresh`) | Strip all codex, then re-init (clean restart) |
| `/aftc-codex-learn` (`/codex-learn`) | Record durable lessons (1.7.5) |
| `/aftc-codex-status` (`/codex-status`) | Viewer: enabled/prepped state, resource counts, installed/not-installed row |
| `/aftc-codex-install` (`/codex-install`) | Wipe + restore the shipped basics (rules + guidance). Confirmation in the TUI; headless refuses |
| `/aftc-codex-list` (`/codex-list`) | List EVERY available codex load resource - scrollable full-screen MODAL with type-to-filter (first item highlighted, ↑/↓ to move, Esc/Enter closes); headless prints the same list. Read-only: works enabled or not; warns when nothing is created yet |
| `/aftc-codex-load` (`/codex-load`) | Pick ONE codex resource to load via a scrollable menu with type-to-filter (same pattern as /qd): Enter picks the highlighted resource and the menu CLOSES. ONE marker instruction tells the AI to codex_load that topic now (eager when idle, follow-up when busy). A LOAD action (same as typing "codex load <x>"), not a prep action - rules-only / un-prepped sessions are NOT refused; headless points at /codex-list |
| `/codex-inject-rules` | Session-only rules-only mode (1.7.2) |

## Screen: /codex main menu (surface)

`showMenu`, title "Menu:", body `AFTC Codex: <N> resources available` +
`Session state: Prepped / Not prepped (Run /codex-init to prep the AI) /
Rules-only`. Rows (labelWidth 48, settings-hub convention): `Codex
Enabled | Yes/No` · `Inject Thought Guidance | Yes/No` · `Auto-Detect &
Load Docs | Yes/No` · `Auto Insert Codex Skills to Load into AGENTS.md |
Yes/No` (default No - when on the AI may write/update the codex
resources-to-load list (the AFTC-CODEX-STACK block) in the project's
AGENTS.md / auto-inject files; when off codex never writes them and
/codex-init reports an existing block as left untouched) ·
`Resources & Updates` (sub-menu: Start Fresh / open resource dir). Enter
flips toggles and re-renders (selection preserved); Esc closes.

## Screen: resources & updates (surface)

`Start Fresh` (confirm-destructive: wipes the whole live codex - rules,
guidance AND your resources - and re-copies the shipped basics) · `Open
Codex Resource Dir` (opens the live `resources/` folder in the OS file
manager).

## Runtime states

- Headless menu attempts → guidance line pointing at the status command.
