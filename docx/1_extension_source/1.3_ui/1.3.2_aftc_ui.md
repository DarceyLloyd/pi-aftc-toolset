## Function

The AFTC UI toolkit: a fixed high-contrast palette plus GRUB-style
full-screen takeover screens — every cell painted with the background
colour, a centred bordered panel, hints below it, so underlying pi content
never bleeds through and the active element is always obvious. Owns all
overlay primitives; does NOT own any specific feature screen (those are
surfaces in the [sitemap](../1_tui_sitemap.md)). Source: `ui/aftc-ui.ts`
(1212 lines). Palette/focus design rules: [design.md](../../design.md).

## Palette (`AFTC_UI_DEFAULTS`, frozen)

| Token | Value | Use |
| --- | --- | --- |
| background | `#000000` | screen/panel fill |
| text | `#ffffff` | primary text |
| accent | `#fca02f` | titles, values, active markers |
| border | `#555555` | inactive borders |
| selectionBg | `#2d1d08` (accent darkened 0.18) | active row/input bar |
| muted | `#999999` | hints/help |
| error | `#ff5555` | inline validation errors |

Helpers: `hexToRgb`, `darken(hex, factor)`, `defaultAftcPalette()`.

## Public API

### Primitives
- `AftcSpan {text, fg?, bg?, bold?}` + `renderSpan`, `spansWidth`,
  `fitSpans`, `renderSpans(spans, width, palette, colourPolicy?)`,
  `blankRun`.
- Panel borders: `panelTopBorder(title, innerW, palette)`,
  `panelBottomBorder`, `panelRow(spans, innerW, palette, fillBg?)`,
  `panelSeparator`, `panelBlank`.
- `composeTakeover(opts)` / `terminalRows(fallback=24)`.
- `AftcUi` class wraps the above (`panelWidth`, `listViewport`, `menuRow`,
  `takeover`, `span`, …) for composite screens (used by 1.6.5, 1.6.9).

### Ready-made overlays (async; `null`/`false` = cancel/Esc)
| Function | Signature (options) | Returns |
| --- | --- | --- |
| `showMenu` | `{title, body?, items:[{value,label,description?}], labelWidth?, initialIndex?, help?, onHighlight?, filterable?}` | `string \| null` |
| `showConfirm` | `{title, body, yesLabel?, noLabel?}` — safe option highlighted by default | `boolean` |
| `showForm` | `{title, fields: AftcFormField[], submitLabel?, validate?}` | `Record<string, unknown> \| null` |
| `showInput` | string input overlay | `string \| null` |
| `showIntInput` / `showFloatInput` | `{label, min?, max?, initial?}` | `number \| null` |
| `showViewer` | `{title, lines \| rows}` scrollable read-only viewer (word-wraps) | `void` |

`filterable` menus (type-to-filter): typing printable chars narrows the item
list (fuzzy match on the label, best matches first - the same `fuzzyFilter`
the retired /cd picker used), Backspace edits the query, Ctrl+U clears it,
and Escape clears the query first (a second Esc closes). Off by default so
existing menus behave exactly as before.

### Form fields (`AftcFormField`)
`{id, label, type?: "string"|"int"|"float"|"choice"|"password", required?,
initial?, min?, max?, maxLength?, options?}`. `AftcForm` enforces: required
non-empty (after trim), int/float bounds, choice membership;
`maxLength` (string/password) is a HARD cap — extra typed characters never
enter the input and pasted text is trimmed to the cap; `validate(raw)`
returns `{fieldId, message} | null` for cross-field rules.

## Focus / active-element contract (normative)

- Exactly ONE element looks active at any time.
- Active menu row / action: full-width selectionBg bar + bold accent `❯`.
- Active input: accent `❯` label, boxed row with accent borders, full-width
  selectionBg behind the value, the ONLY live typing cursor on screen.
  Inactive inputs render their value as plain accent text inside #555555
  borders, no cursor.

## Navigation keys (all menus/lists)

↑/↓ wrap by 1 (menus: `onHighlight` preview hook fires) · PageUp/PageDown
one viewport · Ctrl+PageUp/PageDown or Home/End jump to first/last ·
Enter commits · Esc cancels. Forms: Tab/Shift+Tab move focus, Enter
advances/submits, Esc cancels. Composite screens may extend (1.6.5 uses
Tab focus areas; 1.6.9 forwards keys to the remote).

## Runtime states

- Cancelled → `null`/`false` resolve; callers decide fallbacks.
- Outside TUI (`ctx.mode !== "tui"`): composite overlay wrappers return
  their fallback value (see 1.6.7/1.6.8 headless paths).
- Render errors: every line is width-exact; over-wide output is impossible
  by construction (`truncateToWidth`).

## Rules / invariants

- Leaf utility: imports only `@earendil-works/pi-tui` — any feature may
  import it.
- Settings-hub convention (footer menu, notify hub, codex menu): stable
  label + ` | value` column, selection preserved across toggles, Esc closes.
