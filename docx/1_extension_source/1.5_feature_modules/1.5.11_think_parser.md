## Function

Converts inline `<think>…</think>` TEXT tags in assistant messages (the
DeepSeek/Qwen convention) into proper pi `ThinkingContent` blocks, so the
TUI shows native collapsible thinking (theme `thinkingText`, Ctrl+T
toggle, `hideThinkingBlock` setting) instead of raw markers. Source:
`think-parser.ts` (274 lines). OFF by default
(`thinkProcessingEnabled`); no UI of its own.

## Commands

| Command | Behaviour |
| --- | --- |
| `/aftc-enable-think-processing` | Sets `thinkProcessingEnabled=true` |
| `/aftc-disable-think-processing` | Sets `thinkProcessingEnabled=false` |

## Mechanism

Single `message_end` hook (the only message-replacement hook —
`message_update` cannot replace). Walks `event.message.content`; every
`<think>…</think>` substring of a TextContent block (regex global,
non-greedy, closing tag REQUIRED) is split out into a sibling
ThinkingContent block in source order; non-text blocks pass through.

## Runtime states / skip rules (all normative)

- Preference off → no-op.
- Message already contains a ThinkingContent block → skip (don't fight
  native reasoning providers like Anthropic).
- `stopReason` "error" or "aborted" → skip (never mangle partial output).
- Text block carries `textSignature` → skip (modifying signed text would
  invalidate provider-side signature replay on the next turn).
- Unclosed `<think>` → left as plain text (never swallow half a tag).
- Streaming: raw tags are visible until the turn finalizes, then collapse
  (accepted first-cut behaviour, matches other "strip on finalize"
  providers).
