## Function

Sends a fixed "be concise" instruction prompt to the active model as a
fresh user message — the nudge for when the model drifts into verbose
explanations. Source: `keep-it-short.ts` (140 lines). No state, no events.

## Commands

| Command | Args | Behaviour |
| --- | --- | --- |
| `/keep-it-short` | — | Sends the fixed KIS prompt |
| `/kis` | — | Identical alias |

Delivery: idle → `sendUserMessage` (new turn now); busy → `deliverAs:
"followUp"` (queued until the current turn finishes — safer than "steer";
to interrupt, `/aftc-stop` first, then `/kis`).

## The prompt (verbatim intent)

Be terse; answer the actual question fully in the fewest words; no
preamble/recap/"here's…" openers; drop filler; code stays as code;
one-word replies are fine when they answer; ALWAYS respond with something
("done" at the very least) — "short" means terse, never silent.

## Runtime states

- Success: emphasis `Sent: <80-char preview>` (or queued variant).
- Headless: stdout line with char count.
