## Function

Aborts the currently-running agent operation — the escape hatch when a
reasoning model is stuck in a long internal monologue or a runaway
tool-call loop. Two functionally identical slash commands (registered
separately so BOTH autocomplete): `/aftc-stop` (namespaced convention) and
`/stfu` (type-fastest alias). Source: `stfu.ts` (180 lines). No state, no
events.

## Commands

| Command | Args | Behaviour |
| --- | --- | --- |
| `/aftc-stop` | — | `ctx.abort()` — fire-and-forget cancel of the in-flight provider stream + running tool |
| `/stfu` | — | identical handler |

## Why slash commands when Escape exists

They work regardless of editor focus, are scriptable, discoverable via
`/aftc-help` (both listed as aliases of one action under Interrupt), and
survive being typed in a hurry.

## Runtime states

- Agent busy → abort fires; emphasis "Stopped via /<cmd>".
- Agent already idle (`ctx.isIdle()`) → "Agent is already idle — nothing
  to stop." (never fails silently).
- Headless: same outcomes on stdout.
