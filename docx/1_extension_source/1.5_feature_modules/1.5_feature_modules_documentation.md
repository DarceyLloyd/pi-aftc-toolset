## Purpose

The standalone convenience features — one self-contained file each,
self-registering commands/handlers, no shared state between them, wired by
a single `createXxx(pi)` line in index.ts (1.1). Everything that is not
footer/usage (1.4), SSH (1.6), codex (1.7) or docx (1.8).

## Module contract (applies to all)

- No closure state beyond the feature's own; no cross-module imports
  (config.ts, paths.ts, help-registry.ts, ui/* are shared utilities, not
  features).
- Register help entries next to every command (enforced by the tests/ folder - see AGENTS.md
  enforces sync).
- Guard UI with `ctx.hasUI`; provide a headless path for every command.
- Deliver messages while busy via `sendUserMessage(..., {deliverAs:"followUp"})`.
