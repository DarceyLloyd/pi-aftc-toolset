## Function

Shortcut to pi's themes: discovers all installed themes, opens an AFTC
menu with extended navigation and LIVE preview, commits on Enter, reverts
on Esc. Source: `theme.ts` (155 lines).

## Screen: theme picker (surface)

`showMenu`, title "Select theme", body `Current: <name>` (or "Pick a
theme to switch to"), one item per discovered theme (`ctx.ui.getAllThemes()`),
the active one marked ` (current)` and pre-selected. Help line:
`↑↓ = preview  PgUp/PgDn = page  Ctrl+PgUp/PgDn = top/bottom  Enter =
commit  Esc = revert`.

- Every navigation move applies the highlighted theme live via
  `ctx.ui.setTheme` (`onHighlight` hook) — visible once the picker closes.
- Enter: re-sets the chosen theme definitively (idempotent; retries a
  failed preview); emphasis "Switched to theme: <name>".
- Esc: reverts to the theme active when the picker opened — but ONLY if a
  preview actually changed the theme and a real name was captured (the
  `<in-memory>` sentinel from `setThemeInstance` is skipped).
- Preview failure: warn line, picker stays open.

## Runtime states

- Headless: lists discovered theme names on stdout (no picker).
- No themes discovered: warn "No themes discovered".
- Commit failure: error "Failed to switch theme: …".

## Data

None persisted (pi owns the active-theme setting).
