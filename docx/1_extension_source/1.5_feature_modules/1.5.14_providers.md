## Function

LLM provider integrations. **DISABLED since 2026-07**: pi 0.81 added native
provider support, so `createProviders(pi)` is commented out in index.ts.
The module is kept on disk in case the built-in proves weaker — re-enable
both the import and the call line to restore it. Nothing here is live
behaviour today.

## What the module contains (dormant)

- `providers/index.ts` — folder entry; exports `createProviders(pi)`.
- `providers/qwencloud.ts` — Alibaba Qwen Cloud (DashScope) + Qwen Coding
  Plan via pi's native `/login` (`pi.registerProvider`, credentials stay
  pi-owned in `~/.pi/agent/auth.json` — the extension never reads/writes
  auth.json): live model catalogs with cache/seed fallbacks, and the
  `/qwencloud` management command.
- Config keys still present in config.ts: `qwencloudCloudDomain`,
  `qwencloudCloudApiFormat`, `qwencloudPlanApiFormat`,
  `qwencloudPlanOpenAI`, `qwencloudPlanAnthropic`.

## Runtime states

- Disabled: no commands, no providers registered; `/qwencloud` unknown to pi.
- Re-enabled: previous behaviour returns unchanged.
