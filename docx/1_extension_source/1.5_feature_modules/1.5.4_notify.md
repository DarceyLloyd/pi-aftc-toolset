## Function

Plays MP3 sounds on agent events. The AI model is completely unaware —
pure TypeScript-side event handling, no model tool, no prompt content.
Playback spawns the bundled miniaudio binary (2.1: `extensions/aftc-toolset/bin/`)
detached: no window, no blocking, self-exits when the track ends. Source:
`notify.ts` (592 lines). OFF by default (`notifyEnabled`); fresh installs
are silent.

## Triggers (event → category → preference)

| Trigger | Category | Pref key | Default sound |
| --- | --- | --- | --- |
| `ask_user_question` tool call | question | `notifySoundQuestion` | voc_question_07.mp3 |
| Task completes (`agent_settled`, duration ≥ threshold) | task | `notifySoundTaskComplete` | voc_task_complete_07.mp3 |
| Agent ends with stopReason `error` | error | `notifySoundError` | voc_we_got_a_problem_01.mp3 |
| User aborts (stopReason `aborted`) | aborted | `notifySoundAborted` | `""` (none) |
| Fresh session start (`reason` startup/new) | startup | `notifySoundStartup` | xp.mp3 |
| Context usage crosses 25% / 50% / 75% | context25/50/75 | `notifySoundContext25/50/75` | `""` (none) |

`notifyTimeSec` (default 1) — minimum task duration before the completion
sound; `0` disables time-based completion sound. Context thresholds are
checked on every assistant `message_end` via `ctx.getContextUsage().percent`;
each fires once on the upward crossing and re-arms when usage drops back
below (e.g. after compaction); one message jumping several thresholds plays
only the highest. Threshold state is never reset on session start: every
session start (including /reload, which re-imports the module) pre-marks
thresholds that usage is already at or above, so a session starting at 39%
never replays the 25% sound — only a genuine drop back below a threshold
(e.g. after compaction) re-arms it.

Sounds live in `data/aftc-audio-notifications/{question,task-complete,error,
aborted,startup,context-window/{25,50,75}}/` (2.1).

## Commands & screens

| Command | Args | Behaviour |

| `/aftc-audio-notifications` (alias `/aftc-notifications`) | — | Settings-hub menu (surface) |
| `/aftc-notify-time [sec]` | optional seconds | No arg: show current threshold. With arg: validate + set `notifyTimeSec`. |

### Screen: Notification sounds hub (surface)

`showMenu`, title "Notification sounds", body "Pick which sound to
configure.", labelWidth 31. Rows: `Enabled | Yes/No` (Enter flips) then 8
category rows `Choose sound for <category> | <current sound or NONE>` then
`Open notification sounds dir` (explorer/open/xdg-open). Selection
preserved across toggles; Esc exits. Each category row opens a sound picker
menu listing the MP3s in that category's folder + NONE; choosing stores the
FILENAME in config.json. Headless: prints all current assignments.

## Runtime states

- `notifyEnabled` false: no sound ever plays.
- Missing sound file / empty pref: silent skip (logged to debug.log).
- Spawn failure: swallowed + logged (never breaks pi).
