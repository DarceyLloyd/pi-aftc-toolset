## Purpose

`/copy-all` copies every previous user and assistant message in the current
thread to the system clipboard, joined with `---` separators and prefixed
`USER:` / `ASSISTANT:`.

## Behaviour

- Copies user and assistant **message** entries only (tool calls, tool
  results and other entry kinds are excluded); visible **text** blocks plus
  an `[image]` placeholder for images.
- **Thinking blocks are excluded** — the clipboard gets the visible
  conversation, not the reasoning.
- Always available (a simple read + clipboard command, like `/theme` or
  `/kis`) — no enable flag, no model tool, no background work.
- `await ctx.waitForIdle()` so the copy reflects the settled transcript.
- Reads via `sessionManager.getBranch()` (falls back to `getEntries()`);
  the extractor tolerates both the wrapped `{ type: "message", message:
  {...} }` and flat `{ role, content }` shapes.
- Uses pi's `copyToClipboard` (cross-platform; throws when no clipboard —
  caught and reported via aftc-console).
- Bounded at 2,000,000 chars; oversized threads are truncated and the
  confirmation says so.

## Edge cases handled

- Empty transcript → "No user or assistant messages to copy."
- Clipboard unavailable (headless/Linux) → aftc-console error, no crash.
- Oversized thread → truncated to 2 MB with a note.
- Image blocks → `[image]` placeholder (never dropped silently).
