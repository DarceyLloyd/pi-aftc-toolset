## Screen: AFTC text intro widget (surface)

`intro-text.ts` — one-line typewriter WIDGET (key `aftc-intro`, not a
message: never enters model context or session history). Types "AFTC",
expands to `All For The Code - pi-toolset v<package version> - <quip>`
with a `YYYY-MM-DD HH:MM Today` timestamp. Timings: `START_DELAY_MS=925`
(session_start paint settles first; instant when fired from the command),
`END_DELAY_MS=1900` linger, then self-clears. Preference key `"aftc-intro"`
(default true). Played on `session_start` when enabled; stopped on
`session_shutdown`.

## Commands

| Command | Behaviour |
| --- | --- |
| `/aftc-intro-on` | Enable + play immediately (no start delay). Already ON → say so. |
| `/aftc-intro-off` | Disable + stop. Already OFF → say so. |

## Dormant: WarGames intro

`intro-wargames.ts` — full-screen green typewriter takeover (raw ANSI, alt
screen) + MP3 from `data/aftc-intro/audio/`; preference `warGamesEnabled`
(default false). Not wired while the factory is disconnected.
`tests/intros-check/` drives its takeover contract (alt screen start on
session_start, restore on shutdown) against the dormant module.

## IntroDescriptor contract (factory)

`{id (pref key), label, commandPrefix (auto `/<prefix>-on|off`; "" =
config-only), play/stop/isEnabled/setEnabled}`. Adding an intro: new
`intro-<name>.ts` + factory array entry + preference key + help rows.

## Runtime states

- Enabled + session start: widget types out after `START_DELAY_MS`, lingers
  `END_DELAY_MS`, self-clears.
- Disabled (`aftc-intro` false): nothing plays; `/aftc-intro-on` says
  "already ON" when already on.
- Command-fired play: instant (no start delay).
- WarGames: always dormant while the factory is disconnected — its
  `warGamesEnabled` pref is read by no live code path.
- `session_shutdown`: any running intro is stopped.
