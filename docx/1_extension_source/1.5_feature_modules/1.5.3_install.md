## Function

`/aftc-install` — installs the runtime dependencies pi's extension system
does not install: the `better-sqlite3` native binding (npm) and the
packaged SSH carrier Python environment (locked `uv sync`). Also runs an
intelligent session-start dependency warning. Source: `install.ts`
(305 lines).

## Command & screens

`/aftc-install` flow:

1. Locate the package root + carrier dir (`extensions/aftc-toolset/ssh/carrier`,
   must contain `pyproject.toml`) — else error "reinstall pi-aftc-toolset".
2. Probe: is better-sqlite3 resolvable? uv executable present? Python
   available (`uv run --no-sync … import paramiko, aftc_ssh_carrier`,
   30 s check)?
3. TUI: confirm overlay listing what is missing — "This runs npm install
   and uv sync --locked in the installed package. Continue?"
4. Run `npm install` (300 s timeout) and `uv sync --locked` (600 s timeout),
   then re-verify; result shown in a `showViewer` report (redacted —
   connection data never appears; platform-specific recovery guidance when
   Node/Python/uv is missing).
5. Headless: runs without the confirm, prints progress.

Session-start warning: once per session, when any runtime dependency is
missing, warn line "runtime dependencies may be missing (…) — run
/aftc-install". Stays silent when everything is already installed.

## Runtime states

- All installed: confirm lists only the verification step.
- Missing uv: recovery guidance names the platform installer.
- Timeout: kill + report (self-terminating; never blocks pi).
- Concurrent runs: a single shared install promise (no duplicate work).

## Data

Reads the package's own `package.json` `dependencies` keys to know what to
probe. Writes nothing except what npm/uv write.
