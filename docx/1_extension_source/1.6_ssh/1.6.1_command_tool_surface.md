## Function

The user- and model-facing surface of the SSH feature: 16 slash commands
and 20 model tools, all defined in `ssh/index.ts` (744 lines) on top of the
session manager (1.6.2). Every model-facing string passes redaction (1.6.4);
tool output is bounded (2000 lines / 50 KB, `truncateHead`/`truncateTail`,
full text captured to a local temp file only).

## Slash commands

| Command | Args | Behaviour |
| --- | --- | --- |
| `/ssh-cm` / `/ssh-connection-manager` | — | Open the full-screen connection manager (1.6.5). TUI-only. |
| `/ssh-connect` | `[name]` (quotes for spaces) | Connect a saved connection. Exact match, then case-insensitive; unknown name warns + lists saved names; no name → picker (1.6.7/1.6.5 picker.ts). Saved password used without prompting; else auth flow (1.6.7). New host key → auto-accept or confirm overlay. |
| `/ssh-connections` | — | Viewer listing saved connection NAMES only. |
| `/ssh-status` | — | One-line emphasis: "Connected to a, b" / "Not connected". |
| `/ssh-select` | `[id]` | Select the active session for local commands; no id → active-session picker. |
| `/ssh-disconnect` | `[id]` | Disconnect; defaults to selected; stale id → helpful warning listing active sessions. |
| `/ssh-shell` | — | Open the interactive terminal overlay on the selected session (1.6.9). |
| `/ssh-close-shell` | `<shellId>` | Close an interactive shell. |
| `/ssh-interrupt` | `<shellId>` | Send Ctrl+C + Ctrl+D recovery keys. |
| `/ssh-upload` | `<local> <remote> [--preserve]` | Upload to selected session; existing remote path → replace confirm; `--preserve` keeps timestamps/permissions. |
| `/ssh-download` | `<remote> <local> [--preserve]` | Download; existing local path → replace confirm; `--preserve` keeps timestamps (+ permissions on POSIX). |
| `/ssh-rename` | `<from> <to>` | Rename remote path after confirm (destination exists → "Replace?" wording). |
| `/ssh-auto-accept-session-on` | — | Trust NEW host keys without asking (persisted in ssh.json). Changed keys still rejected. |
| `/ssh-auto-accept-session-off` | — | Restore the new-host-key prompt (default). |
| `/ssh-help` | — | Viewer with the SSH workflow guidance (connect via saved names, shells, Ctrl+] exit, transfers, model tools). |

Remote path removal is deliberately NOT a slash command — destructive
deletes stay with the `ssh_remove` model tool and its local confirmation.

## Model tools (all registered in index.ts)

Session lifecycle: `ssh_status` (list sessions or why not connected +
connect hint), `ssh_connect` (`connectionName` only — reconnect-safe, same
opaque id when already connected, fails safely headless), `ssh_disconnect`
(`sessionId`).

Commands: `ssh_run` (`sessionId, command, timeout? (1–120 s, default 30),
stdinText? (≤64 KiB, never credentials)`) → stdout/stder/exitCode, bounded.

Interactive PTY shells: `ssh_open_shell` (`sessionId` → shellId),
`ssh_send_keys` (`keys[]` — text or named terminal keys), `ssh_paste`
(`text`), `ssh_resize` (`cols 20–500, rows 5–200`), `ssh_close`,
`ssh_peek` (bounded ≤50 KB output read), `ssh_interrupt` (Ctrl+C/Ctrl+D).

SFTP: `ssh_upload` (`localPath, remotePath, preserve?` — local overwrite
approval), `ssh_download` (`remotePath, localPath, preserve?` — local
overwrite approval).

Remote file ops (each requires local-user confirmation for mutations):
`ssh_list_dir`, `ssh_read_file`, `ssh_stat`, `ssh_write_file`,
`ssh_mkdir` (`recursive?`), `ssh_rename`, `ssh_remove` (`recursive?`).

Every tool carries a `promptSnippet` + `promptGuidelines` naming the tool
explicitly (e.g. "Use ssh_run for bounded, non-interactive commands").

## Runtime states

- Not connected: `ssh_status` reports carrier state ("no SSH session yet" /
  "no SSH sessions" / "SSH carrier stopped") + connect hint.
- Headless: `ssh_connect` throws "Cannot connect from headless mode…" —
  credential collection needs the TUI.
- Unknown session/tool ids: model-friendly errors via safe mapping (1.6.4).
