## Function

File transfer and SSH port forwarding. Sources: `sftp_ops.py` (524),
`port_forward.py` (535).

## SFTP (sftp_ops.py)

Methods: `upload`, `download`, `cancel_transfer`, `read_file`,
`write_file`, `list_dir`, `mkdir`, `rename`, `remove`, `stat`, `chmod`,
`chown`.

Contract (normative):

- Upload/download accept regular files OR directory trees; symlinks are
  never followed or recreated; empty directories and binary files
  supported.
- Every SFTP operation holds a per-session lock for its whole duration —
  paramiko's synchronous response reader is unsafe for concurrent threads
  sharing one SFTPClient. `cancel_transfer` NEVER takes that lock.
- Transfers run in fixed chunks so a concurrent `cancel_transfer` (opaque
  transfer id) can abort a large transfer; on cancel/failure the temp
  file is removed, then the destination is replaced atomically where the
  filesystem supports it.
- In-flight `transfer_progress` notifications (transferId, bytes, total)
  for live progress surfacing.
- `preserve` (opt-in): upload restores remote mtime/atime + permission
  bits; download restores local mtime/atime (+ permission bits on POSIX).
- Errors map to typed codes: -32020 file not found, -32021 permission
  denied, -32022 path is directory, -32060 transfer cancelled.

## Port forwarding (port_forward.py)

`forward_local` (local→remote), `forward_remote` (remote→local),
`forward_dynamic` (SOCKS-style), `list_forwards`, `cancel_forward`
(opaque forward id; -32006 unknown forward, -32030 port in use). Used by
the SSH test suites and advanced workflows; the TS model tools do not
currently expose forwarding (commands/tests cover it — see AGENTS.md
suite, 3.3).

## Runtime states

- Transfer in flight: `transfer_progress` notifications stream; a
  concurrent `cancel_transfer` aborts, removes the temp file and returns
  -32060.
- Missing source / permission trouble / dir-vs-file mismatch: -32020 /
  -32021 / -32022 respectively.
- Forward bind failure: -32030 (port in use); cancel of unknown forward:
  -32006.
- Atomic replace unsupported by the filesystem: plain overwrite fallback.
