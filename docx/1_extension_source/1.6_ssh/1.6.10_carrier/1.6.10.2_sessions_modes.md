## Function

Paramiko session lifecycle plus the two command modes and the connection
monitor. Sources: `session.py` (434), `shell_mode.py` (311),
`exec_mode.py` (127), `monitor.py` (165).

## Sessions (session.py)

- `connect` opens the Paramiko transport/client: host, port, username,
  password and/or identity file (passphrase supported), connect timeout.
  Host-key handling: unknown key → `HOST_KEY_UNKNOWN` (-32041, the host
  may re-connect with approval); CHANGED key → `HOST_KEY_CHANGED`
  (-32042, never overridable).
- Multi-session registry keyed by carrier session id; `disconnect`,
  `list_sessions`, `get_session`; `all_sessions_snapshot()` for the
  monitor.

## Exec mode (exec_mode.py) — `run`

Non-interactive exec channel: optional bounded `stdinText` (≤64 KiB
UTF-8), per-stream output caps (256 KiB each, `truncated` flag), exit
code, timeout → `COMMAND_TIMEOUT` (-32010). `expect` provides a
pattern-wait variant.

## Shell mode (shell_mode.py) — interactive PTY

`open_shell` allocates a PTY channel per shell id; `send_keys` translates
symbolic names via 1.6.10.4 `keys.py` (ctrl chords, arrows, F-keys,
aliases, case-insensitive); `paste` writes raw text; `peek` returns
bounded scrollback/screen bytes (≤50 KB at the tool layer);
`resize_shell` resizes the PTY; `interrupt_shell` sends Ctrl+C/Ctrl+D;
`close_shell`/`list_shells` manage lifecycle.

## Monitor (monitor.py)

Background thread polling every 5 s (cheap `transport.is_active()` check).
On a dead transport it invokes the daemon callback → `session_lost`
notification + removal of JUST that session. It MUST NOT self-terminate
the daemon (AFTC contract). Also hosts the TS-independent idle backstop:
stdin quiet beyond `AFTC_SSH_IDLE_TIMEOUT_SEC` (default 600 s) with no
sessions/shells/forwards/in-flight work → self-exit.

## Runtime states

- Connect: unknown host key → -32041 (approvable); changed key → -32042
  (always rejected); auth failure → -32003.
- `run`: timeout → -32010 with whatever output arrived; streams capped at
  256 KiB each with `truncated: true`.
- Shell: open → shellId; unknown shell id → -32005; closed channel →
  -32011.
- Transport death: session pruned + `session_lost`, daemon keeps serving
  the other sessions.
- Idle backstop: quiet stdin + no active work → clean self-exit 0.
