## Function

Two connect/edit-time surfaces: the EDIT connection form and the
connect-time credential collection. Sources:
`ssh/connection-form-overlay.ts` (149 lines — overlay wrappers) +
`ssh/connection-form.ts` (141 lines — flows + headless fallbacks).

## Screen: edit connection form (surface)

`connectionFormOverlay` → `showForm`, used by the manager's Edit flow
(1.6.5) via `editConnectionSettings`. Fields: name / username / host
(required), port int 1–65535 (label shows current; empty keeps), timeout
int 1–300 s (empty keeps), private-key path, auth-method CHOICE field
(Password / Private key; pre-selected from identityFile). Cross-field
validation: key auth requires a key path ("A private-key file path is
required for key auth."). NO password field by design — a saved password
survives edits. Cancel → null (record untouched). Outside the TUI → null,
caller falls back to sequential per-field `ctx.ui.input` prompts
(`editConnectionByField`: username, host, port, timeout, key path with
`-` to clear; validation messages via `ctx.ui.select`).

## Screen: auth method menu + credential prompts (surface)

Connect-time flow (`createSavedConnectionRequest`):

1. Saved password present → used directly, no prompt.
2. TUI: `authMethodOverlay` — single-question `showMenu` "SSH
   authentication" with Password / Private key (initial from the
   connection's identityFile).
3. Password → `ctx.ui.input("Enter password. It is used only for this
   connection attempt.")` — required: empty → error select "A password is
   required.", then null. Key → optional passphrase input ("leave empty
   for an unencrypted key").
4. Headless: `collectCredentialsByField` — method select then the same
   prompts.

Returns `SshConnectRequest {connection, credentials{password? ,
identityPassphrase?}}` or null on cancel.

## Runtime states

- Outside TUI: overlays resolve their fallback values (form → null,
  auth method → the initial method) so callers continue with per-field
  prompts.
- Cancel at any step → null; the connect aborts with a model-friendly
  "cancelled locally" error (1.6.1 connectSaved).

## Rules / invariants

- Credentials are used ONLY for the connection attempt (password) or the
  key unlock (passphrase); they never enter model context (1.6 security
  model). Whitespace in passwords is preserved verbatim
  (ssh-connection-form-check asserts this).
