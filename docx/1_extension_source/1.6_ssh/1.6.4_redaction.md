## Function

The privacy filter at the SSH module boundary: strips connection metadata
and secrets from any text that can leave the module toward the model, and
maps every thrown error to a safe, non-diagnostic category. Source:
`redaction.ts` (68 lines).

## API

- `redactSshValues(text, values)` — replace arbitrary sensitive values with
  `[redacted]` (longest-first, de-duplicated).
- `redactSshText(text, connection)` — redacts username, host, port,
  identityFile, password (exact pass, then case-insensitive host +
  key-path passes).
- `sshSafeError()` — generic `Error("SSH operation failed. Check the local
  connection configuration.")`.
- `sshSafeErrorMessage(error)` — category mapping; numeric carrier codes
  carry no endpoint/credential data so they map safely:
  - `-32010` → "SSH command timed out."
  - `-32060` → "SSH transfer was cancelled."
  - message matches /cancelled/i → cancelled; /timed out/i → timed out;
    "session is not connected" → not connected; "carrier is unavailable" →
    "SSH session is unavailable. Reconnect and try again."
  - anything else → the generic safe message.

## Rules / invariants

- Host, user, port, key path, password, passphrase, fingerprint and carrier
  diagnostics NEVER cross to the model — only the safe outcome categories
  above.
- The same redaction is applied to tool output (1.6.1 `boundToolOutput`
  pipeline) and to the session manager's `redactText`.

## Runtime states

Pure functions; no state. Empty/undefined values are skipped.
