## Purpose

Isolated SSH for pi: saved connections managed locally, a packaged Python
(Paramiko) carrier spoken to over local stdio, 20 model tools and 16 slash
commands, full-screen connection management and an interactive PTY
terminal. Owns everything under `extensions/aftc-toolset/ssh/` except the
carrier sub-project folder (1.6.10). Does NOT own: pi session state, the
data dir itself (1.2), overlay primitives (1.3.2).

## Security model (normative — the whole design hangs on it)

1. **Saved connections** live in `<dataDir>/ssh.json` (1.6.3) — local-only,
   never exposed to the model. Managed exclusively through `/ssh-cm`.
2. **Model-facing surface accepts only saved names + opaque session/shell
   ids.** `ssh_connect` takes NO host/user/port/password/key parameters;
   credentials are collected locally (1.6.7) and stay in the extension.
3. **Redaction** (1.6.4): every string leaving the module toward the model
   has username/host/port/key-path/password replaced with `[redacted]`;
   errors are mapped to safe category messages (timeout, cancelled, not
   connected, unavailable) — never carrier diagnostics.
4. **Destructive operations ask**: host-key approval, upload/download
   overwrite, rename/remove/mkdir/write via local confirmation overlays
   (1.6.8) or the model-tool approval paths.
5. **Changed host keys are always rejected** by the carrier; only NEW keys
   can be approved (optionally auto, `/ssh-auto-accept-session-on`).

## Architecture

```
model tools + slash commands (ssh/index.ts, 1.6.1)
        │
SshSessionManager (session.ts, 1.6.2) — opaque ids, selection, reaper
        │ JSON-RPC over stdio (carrier.ts client)
aftc-ssh-sidecar (1.6.10) — Paramiko, PTY, SFTP, forwarding, monitor
```

`carrier.ts` (410 lines) is the local JSON-RPC client: spawn
(`uv run --locked --project <carrier-dir> python -m aftc_ssh_carrier`,
`uv.exe` on Windows), 15 s start timeout, 60 s default request timeout,
1 MB max RPC line, states `idle → ready → terminated`, stop grace 3 s.
The carrier opens NO listening socket — stdio only.

## Configuration

- `ssh.json`: `{connections: SshConnection[], ssh_session_auto_accept}`.
- No config.json keys. `/ssh-auto-accept-session-on|off` toggle persists
  in ssh.json.

## Setup & first run

1. `/aftc-install` (1.5.3) ensures Python + uv + the locked carrier env.
2. `/ssh-cm` → Add new connection (1.6.6) → save.
3. `/ssh-connect [name]` (or the `ssh_connect` tool) → use tools/commands.

## Operational notes & known limitations

- Idle carriers are reaped after a 30 s grace (`REAPER_GRACE_MS`); a
  reconnect cancels the reap.
- Model-facing tool output is bounded to 2000 lines / 50 KB
  (`truncateHead/Tail`); over-long output is also captured to a LOCAL temp
  file (`pi-aftc-ssh-output.txt`) whose path is mentioned but whose
  content never returns to the model.
- Carrier command streams cap at 256 KiB each (truncated flag).
