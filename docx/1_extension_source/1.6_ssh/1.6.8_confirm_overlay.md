## Function

The reusable two-button confirmation dialog of the SSH feature (and, by
reuse, of other features). Thin wrapper over 1.3.2 `showConfirm`:
GRUB-style full-screen takeover with the SAFE option highlighted by
default; outside the TUI it falls back to `ctx.ui.confirm`, so
non-interactive callers behave exactly like the built-in. Source:
`ssh/confirmation-overlay.ts` (38 lines).

## API

```ts
confirmOverlay(ctx, { title, body, yesLabel? = "Confirm", noLabel? = "Cancel" })
  → Promise<boolean>   // true = yes action; false = no action or Esc
```

## Runtime states

- Yes → true; No or Esc → false.
- Headless/non-TUI → built-in `ctx.ui.confirm` semantics.

## Rules / invariants

- The safe option is ALWAYS the highlighted default.
- The body states the consequence plainly; no credentials or host
  diagnostics in titles/bodies.
