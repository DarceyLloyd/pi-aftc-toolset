## Function

Owns ALL telemetry state: session cache/token/cost accumulators, per-tool
schema-cost cache, prefix-shape churn tracker, context-window clock,
per-turn thinking/response timings, the task timer, skill-usage tracking
and the timeframe-averages aggregate. Returns the `FooterDataProvider`
(types.ts) that the widget (1.4.2) reads. Never renders, never calls
`ctx.ui.setWidget`. Source: `core.ts` (1315 lines).

## Commands

| Command | Args | Behaviour |
| --- | --- | --- |
| `/cache-profile` | — | Viewer: per-tool schema token costs (active vs configured, bar chart), skills loaded count/tokens, cache prefix shape (system/tools/prefix hashes, est. prefix tokens), churn diff vs last turn, session totals. |
| `/cache-stats` | — | Viewer: current-context cache statistics (turns, totals, aggregate + recent hit rate, last turn), cache-write ROI (net saved, payback turns), total cost, context cost rate (time, $/hr, $/min), prefix shape, last churn. |
| `/cache-reset` | — | Zeroes accumulators + timing for debugging. Emphasis confirmation. |
| `/cls` | — | Clears the terminal screen (ANSI `2J` + cursor home). |

## Events consumed

`session_start` (load timeframe pref + legacy-key migration, reset
accumulators/timing, capture model, prime tool cache) · `model_select` /
`thinking_level_select` (labels only — never reset clock/cost) ·
`before_agent_start` (capture system prompt, refresh ACTIVE tool cache,
capture loaded skills) · `agent_settled` (finish task timer, classify via
last assistant stopReason → record task row) · `input` (streaming-behaviour
steer/followUp detection, `/skill:name` detection) · `tool_result` (mark
skill used when its SKILL.md/baseDir is read successfully) ·
`message_start` (user: prompt classification + task-timer start + context
clock start; assistant: per-turn clock) · `message_update` (first visible
output ends "thinking") · `message_end` (timings, accumulators, turn row
via the TurnRecorder 1.4.4, churn detection with warn, context-usage
snapshot) · `session_compact` (shape reset) · `agent_end` (headless
stdout line only).

## Timeframe definitions (footer line 4)

Exported `FOOTER_TIMEFRAMES` (19 windows): rolling `1h…72h` ("Last N
hours", cut = now − N h) and date-based `1d/2d/3d/5d/7d/month/3m/6m/1y`
anchored to LOCAL calendar boundaries (`startOfDay`, `startOfDayNDaysAgo`,
`startOfMonthNMonthsAgo`, `startOfYear`). Default key `3d`. Legacy
mapping: `today→1d`, `28d→month` (`resolveFooterTimeframeKey`, rewritten
on disk at session start). Stats refresh throttled to 10 s (immediate on
timeframe change); DB unavailable → zeros. Avg task time averages
`stop_reason='complete'` rows only.

## Runtime states

- Pre-first-turn: all zeros; timeframe row populated eagerly on first read.
- Churn: `Cache prefix changed: system|tools|unknown` warn + log.
- `agent_settled` with last stopReason `toolUse`: duration recorded but
  NOT tagged complete (protects the Task Time metric).

## Rules / invariants

- All expensive work (tool cost, shape hashing) is event-driven and cached;
  the widget render only formats. `onTick()` recomputes the session clock
  and timeframe stats at 1 Hz.
- Hit-rate formula per [parent doc](./1.4_footer_usage_documentation.md).
