## Purpose

Session telemetry: cache/token/cost accumulation and prefix-shape tracking
(1.4.1), the themed footer widget that displays it (1.4.2), subscription
allowance fetching for footer line 5 (1.4.3), per-turn SQLite recording
(1.4.4) and the HTML usage report over the recorded history (1.4.5).

Owns: `core.ts`, `footer-widget.ts`, `allowance.ts`, `usage-recording.ts`,
`usage-report.ts`. Does NOT own: the DB file/schema (1.2 `db.ts`), the
config keys it persists (1.2 `config.ts`), rendering primitives (1.3).

## Data flow

```
pi events ──→ core.ts (accumulators, timing, shape, task timer)
                │ message_end ──→ usage-recording.ts ──→ turns.db (tasks table via recordTask on agent_settled)
                │ FooterDataProvider getters
                ▼
        footer-widget.ts (1 Hz ticker, renders lines 1–5)
                ▲                              allowance.ts (fetch providers / response headers)
                └── /aftc-footer menus          reads turns.db ──→ usage-report.ts ──→ <dataDir>/usage-report/ + local server
```

Wiring: index.ts passes the recorder into `createCore`, the allowance
provider into core, and core's `FooterDataProvider` into the widget (1.1).

## Commands & surfaces of this branch

`/cache-profile`, `/cache-stats`, `/cache-reset`, `/cls` (1.4.1) ·

`/usage-report`, `/usage-clear` + the report app's 5 tabs via the local server (1.4.5).

## Key formulas (normative)

- Cache hit: `hit% = cacheRead / (cacheRead + input)` — pi's `input` is NEW
  prompt tokens only; never divide by `input` alone.
- Thinking time = request-sent → first visible output; response time =
  request-sent → message end. Averages over the last 10 turns.
- Task time = first `agent_start` of a user prompt → `agent_settled`; runs
  through questions/retries/compaction. Failed tasks are recorded but never
  averaged into Task Time (only `stop_reason='complete'` rows).
