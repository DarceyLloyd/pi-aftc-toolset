## Function

Renders the cache-diagnostics bar as a `setWidget` below the editor —
lines 1–4 plus a conditional line 5 — and owns the `/aftc-footer` settings
menu. Line 6 (sub-agents) is always visible while the feature is
enabled — hidden only when the feature is disabled or its
`footerLineEnabled` toggle is off. It is supplied by the orchestrator
as an `extras.subAgentLine(colors)` callback: the widget passes its
c1/c2/c3 color helpers (`FooterLineColors`) and the callback returns an
already-themed line (or null to hide). The widget renders it without
importing the feature (see 1.9.6).
menu, the timeframe picker, the 1 Hz ticker and the show/hide lifecycle.
Reads data via the `FooterDataProvider` (1.4.1); never imports core.ts.
Source: `footer-widget.ts` (643 lines). Composes alongside other footer
extensions (e.g. pi-bar) instead of replacing them.

## Screen: the widget (surface)

Defined by `ctx.ui.setWidget("aftc-cache", factory, {placement:"belowEditor"})`.
Every line starts with `│ ` and is wrapped in `customMessageBg` + dim,
truncated/padded to pane width (`truncateToWidth`, ANSI-aware). Colours:
three logical theme roles — c1 accent+bold (highlights), c2 text
(labels/units), c3 dim (values/dividers) — so the bar retones on any theme
switch.

| Line | Segments (in order) |
| --- | --- |
| 1 | model · THINKING-LEVEL │ CTX Window size (use %) │ Turn Cache % / Session Avg % (+ trend arrow) │ Cached tok / New tok |
| 2 | Prompts: User n / AI n │ Turn cost $ │ Task Time │ Session Time │ Session Time Cost $ │ $/hr │ $/min |
| 3 | Turn Time (last/avg) │ Turn Response Time (last/avg) │ N Tools ~tok │ Skills used u/a (only when skills exist) |
| 4 | `<window> Averages:` cost │ Prompts: User n / AI n │ Avg Cache % │ Avg Task Time — hidden when `footerAveragesEnabled` is off |
| 5 | Allowance: ChatGPT single window "% Allowance used. Resets in: …" or `<provider>: 5h allowance used: % │ Weekly …` — hidden for unsupported providers |

Formatters: token values cap at K ("12Kt"); money per report rules
(`fmtMoney`: `$0.00` / 4dp under $1 / 2dp / thousands separators);
durations adaptive ("5m 30s", "2h 14m", "1d 2h").

## Screen: /aftc-footer menu (surface)

`showMenu` settings hub (selection preserved, Esc closes), items:
`Enable footer | ON/OFF` · `Show recorded averages | ON/OFF` ·
`Set averages timeframe | <current label>`. Headless fallback prints the
three settings on stdout. Toggles persist immediately (config.json 1.2)
and re-render the loop so the value column stays current.

## Screen: timeframe picker (surface)

`showMenu`, title "Set averages timeframe", body explains rolling
windows, lists the 19 windows (1.4.1) with rolling hints and a
`(current)` marker pre-selected. Enter applies (`setTimeframe` →
config + immediate stats refresh); Esc returns to the footer menu.

## Data stored / read

Prefs: `footerEnabled`, `footerAveragesEnabled`, `footerTimeframe` (1.2).
Line 4 reads turns/tasks via core's throttled aggregate; line 5 reads the
allowance snapshot (1.4.3).

## Lifecycle & states

- Shown on `session_start` when `footerEnabled`; hidden via menu
  (`setWidget(undefined)`); component disposed on hide, recreation and
  `session_shutdown` (stops the 1 Hz ticker — recreations otherwise leak
  timers).
- Ticker: every 1 s `data.onTick()` + `tui.requestRender()`, wrapped in
  try/catch (one error must not kill the timer).
- Render error → single red ` Footer error: <msg>` line (never throws).
- Pre-first-LLM-response: context-use % segment omitted (null snapshot).
