## Function

Three pi themes shipped with the package (`package.json` `pi.themes` →
`./themes`). Each is a JSON file with `$schema` pointing at pi's
theme-schema and a `name` + `vars` map defining all of pi's required
theme tokens (bg/fg, accents, panels, success/error/warning, markdown,
syntax, tool diffs, thinking-level borders, …).

| File | Character |
| --- | --- |
| `aftc-black-n-blue.json` | Dark catppuccin-ish base (#1e1e2e) with teal accent (#6bd7ca) + blue secondary |
| `aftc-orange-viz.json` | The AFTC orange visualisation theme |
| `cache-viz.json` | Cache-visualisation variant |

## Usage

Switch via `/theme` (1.5.10) or pi's own theme picker. The footer widget
retones automatically on switch (its three colour roles map to theme
tokens, 1.4.2); the response divider recolours immediately (1.5.5).

## States

Theme parse failure: pi reports it; `/theme` preview shows the failure
warn and keeps the picker open (1.5.10).
