## Function

34 pi skills shipped with the package (`package.json` `pi.skills` →
`./skills`). Each is a folder with a `SKILL.md` (frontmatter `name` +
`description` + body); pi loads them into the system prompt as text
blocks and activates them via `/skill:<name>` or when the model reads the
SKILL.md. Skills are NOT tools — they never appear in the tool list (the
footer counts them separately, 1.4.1).

## Inventory

Toolset-workflow skills (drive this package's own features):

| Skill | Drives |
| --- | --- |
| `aftc-codex` | the 1.7 knowledge base: codex_load, lessons, structure maps |
| `ssh` | the 1.6 SSH feature: commands, PTY shells, transfers, remote files |
| `bulk-read` | concatenate many files into one markdown doc; helper `scripts/bulk-read.mjs` reports size/line count and warns past pi's 2000-line/50 KB read truncation with chunked offset/limit instructions |

## Usage surface

`/skill:<name>` pulls a skill into context explicitly; the model also
reads a SKILL.md when a task matches (core.ts marks the skill "used" on a
successful `read` of its SKILL.md/baseDir — footer "Skills used u/a").
`/aftc-help` lists the curated starting points (1.5.2).

## States

Skill unavailable/not loaded: `/skill:<name>` is unknown to pi; nothing
breaks. Skills read from disk per session — package updates replace them.
