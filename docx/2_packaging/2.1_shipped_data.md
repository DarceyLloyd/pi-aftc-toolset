## Function

Source-only defaults + assets, replaced on every `pi update`; never copied
wholesale to live (one-way per-feature flows). Never mix two features'
files here.

## Contents

### extension-config.json
Package-shipped values: `{"codexVersion": 9}` today. NEVER copied to live.
Bump rule: when the codex seed changes (entries/topics synced into
`data/aftc-codex/`), bump `codexVersion` in the SAME release — without the
bump users get no mismatch notice and never receive the new content (the
live copy is never auto-overwritten). `/codex-live-to-seed` does the bump
when it wrote seed files; hand edits bump manually (1.7.5).

### aftc-codex/ — the knowledge-base seed (1.7)
`codex-rules.md` (Critical Global Rules + per-topic conventions),
`thought-and-action-guidance.md`, `markdown-guidance.md`,
`codex-resource-removal-list.json` (cumulative list of obsolete resource
paths, eg `["frameworks/aftc-framework.md"]` — read from the seed dir by
`/codex-sync` + auto-sync and applied to the live copy before the merge;
never copied live, users never need it; idempotent so it only grows),
and `resources/` with the generated `codex-resource-list.md` + category
folders: `database/`, `design/`, `engines/`, `frameworks/`, `languages/`
(cpp, css, html, javascript, php, pinescript, python, scss, typescript),
`libraries/`, `os/`, `runtimes/`, `tools/` (apache, bash, batch, bun,
cmake, composer, docker, electron, ffmpeg, git, headless-chrome, mysql,
nginx, npm, ollama, pi-extension, powershell, puppeteer, …). Layout
mirrors the live copy 1:1.

### aftc-audio-notifications/ — notify MP3s (1.5.4)
Category folders `question/`, `task-complete/`, `error/`, `aborted/`,
`startup/`, `context-window/{25,50,75}/` with the shipped MP3s (defaults:
`voc_question_07.mp3`, `voc_task_complete_07.mp3`,
`voc_we_got_a_problem_01.mp3`, `xp.mp3`). Plus `WARNING.txt` and the
audio-processing scripts: `process_mp3s.py/.bat` (normalise volume + trim
silence, overwrite mono @ fixed sample rate) and `process_wavs.py/.bat`
(same + create MP3). DO NOT RUN the scripts casually — they overwrite the
shipped audio in place.

### aftc-intro/ — intro assets (1.5.13)
`audio/` (WarGames greeting `voc_greetings-professor-falcon.mp3` + its
processing scripts) for the dormant WarGames intro.

## Related players binary (sibling folder)

The audio PLAYER is not in data/: `extensions/aftc-toolset/bin/` holds
`play_sound-win-x64.exe` (+ macOS names `play_sound-macos-arm64/x64`) and
its C source (`src/play_sound.c` + `miniaudio.h`, public-domain / MIT-0).
notify.ts (1.5.4) resolves the platform binary from there; missing binary
→ silent no-op.
