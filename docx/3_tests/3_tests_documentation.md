## Function

All test suites live in `tests/` at the repo root. The `tests/` folder is
gitignored and NEVER committed - that is why this doc contains no test
information: docx documents the source, and tests are developer-side tooling
that does not ship.

**How to run and use the tests is in AGENTS.md** (which suites to run, the
watchdog timeout rules, the "never run the full suite unprompted" policy, the
Linux container verification cycle, and the docx-tests rule). This is the
only doc that says anything about tests.
