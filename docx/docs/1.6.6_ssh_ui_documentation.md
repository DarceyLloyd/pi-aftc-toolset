## Purpose

**Owns:** all local SSH interaction — collecting connection/credential input, choosing connections/sessions, destructive-action confirms, and the interactive PTY terminal.
**Does not own:** carrier protocol (1.6.3), persistence (1.6.5).
**Depends on:** 1.3 (aftc-ui primitives), 1.6.2, 1.6.5. **Dependents:** 1.6.1.

## Public API & contracts

- `connection-manager/` — `/ssh-cm` full-screen manager (add/edit/delete).
- `connection-form.ts` + `connection-form-overlay.ts` — validated form (host/user/port/auth method/password/key path) mapped onto `showForm`/`showMenu`.
- `picker.ts` — connection/session pickers (`showMenu`).
- `confirmation-overlay.ts` — destructive-action confirms (`showConfirm` wrapper).
- `terminal-overlay.ts` — `/ssh-shell` full-screen terminal (Ctrl+] exits) with a VT100 virtual screen.

## Internal architecture & data flow

All screens compose the aftc-ui primitives (GRUB-style takeover or `showForm`/`showMenu`). Credentials collected here are passed straight to 1.6.2 for one auth attempt — never logged, never returned to the model. The terminal overlay renders PTY bytes into a VT100 screen model (SGR colours, cursor addressing, erase, scroll, alt-screen) and sends keystrokes back through the session.
