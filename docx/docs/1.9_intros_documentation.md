## Purpose

**Owns:** the startup intro (`intro-text.ts`) and the disconnected intro factory files (`intro-factory.ts`, `intro-wargames.ts`, ...).
**Does not own:** audio (1.5 notify, 1.11 binaries).
**Depends on:** 1.1, 1.2 (config `aftc-intro`). **Dependents:** none.

## Public API & contracts

`createTextIntro() -> { isEnabled(), setEnabled(bool), play(ctx, startDelayMs?), stop(ctx) }`. Commands `/aftc-intro-on` / `/aftc-intro-off` are registered directly in `index.ts` (with help-registry entries).

## Internal architecture & data flow

The text intro is a raw ANSI alternate-screen takeover (`\x1b[?1049h`/`\x1b[?1049l`), hidden cursor, absolute-positioned repaint on a ~250ms heartbeat, any-key dismiss, max-time failsafe — chosen because pi UI overlays from `session_start` are dropped/flaky (no TUI-ready event). Played on `session_start` when enabled (default delay lets pi's startup paint settle); stopped on `session_shutdown`. The factory (random draw across intros incl. WarGames) was disconnected 2026-07 — files kept on disk; re-enable in `index.ts` to restore.

## Configuration

`aftc-intro` (true), `warGamesEnabled` (false — the WarGames intro's own flag).
