## Purpose

**Owns:** the mechanical steps of a generation run that a model should not hand-perform.
**Does not own:** the decision to run them (the guide's steps 1/11/12).
**Depends on:** adm-zip (zip-old only). **Dependents:** the model via bash.

## Public API & contracts

- `map-scan.mjs <projectRoot>` — recon skeleton on stdout: exclusion-aware directory tree (dirs + notable files), manifest inventory with exact dependency versions, container inventory (Dockerfiles, compose services), test surfaces, CI files. Depth/entry capped.
- `link-audit.mjs <projectRoot>` — mechanical audit: every markdown link target resolves; every prose reference to a `./docx/` markdown path exists; every `last-reviewed`/`last-verified` stamp matches `YYYY-MM-DD HH:MM`; every ID-prefixed file's H1 starts with its ID AND every H1-with-ID has an ID-prefixed filename; every map ID has exactly one deep doc (sub-maps counted separately, max one per ID); `docx/` layout guard (only `project_documentation.md`, `project_map.md`, `docs/`, `generation-plan.md`, `old_docs/`, `old_docs.zip` allowed; `docs/` holds files only). Exit 1 with failures listed.
- `zip-old.mjs <projectRoot>` — zips `docx/old_docs/` to `docx/old_docs.zip` (fixed name, overwrite intended — the previous zip was folded in by the backup), verifies entry count == disk file count, then deletes `old_docs/`. Empty/missing staging folder = clean no-op.

## Internal architecture & data flow

Plain Node ESM, no shell, self-terminating watchdogs, exit 0/1. The model runs them via absolute paths substituted into the prompt by 1.8.1.

## Configuration

None.

## Setup, seeding & first run

adm-zip via npm install (`/aftc-install`).

## Testing

All three are covered by `tests/docx/docx-check.mjs` (scan output shape, audit pass/fail matrices incl. layout guard + filename-ID check, zip verification + fold-in).

## Operational notes & known limitations

- link-audit separates deep docs from sub-maps when pairing IDs (an ID may have one of each) — a count that conflated them once forced a model to embed sub-maps; fixed and covered by fixtures.
