## Purpose

**Owns:** all small slash-command features and keyboard shortcuts.
**Does not own:** SSH (1.6), codex (1.7), docx (1.8), footer (1.4) — those are branches of their own.
**Depends on:** 1.1, 1.2, 1.3. **Dependents:** none.

## Public API & contracts

| Module | Command(s) | What it does |
| --- | --- | --- |
| `help.ts` + `help-registry.ts` | `/aftc-help` | Grouped command/shortcut reference rendered from the registry; every `registerCommand` must have exactly one `registerHelpEntry` beside it (drift-tested) |
| `install.ts` | `/aftc-install` | Installs runtime deps (npm install + uv sync for the carrier); session-start dependency warning |
| `keys.ts` | `/aftc-cut-input` | All global shortcuts: `alt+c` clear editor, `alt+n` newline at caret, `alt+x` cut input to clipboard (shares one handler with the command) |
| `theme.ts` | `/theme` | Theme picker (pre-selects active theme) |
| `stfu.ts` | `/aftc-stop`, `/stfu` | Emergency abort of the current agent operation |
| `dir.ts` | `/dir`, `/ls` | Platform-native directory listing card |
| `cwd.ts` | `/cwd` | Current working directory card |
| `replay.ts` | `/save-replay-prompt`, `/replay` | Save a prompt string, re-send it (follow-up when busy) |
| `keep-it-short.ts` | `/keep-it-short`, `/kis` | Fixed "be terse" prompt to the model |
| `think-parser.ts` | `/aftc-enable-think-processing`, `/aftc-disable-think-processing` | `message_end` hook converting inline `<think>` tags to native ThinkingContent (off by default) |
| `notify.ts` | `/aftc-audio-notifications`, `/aftc-notify-time` | MP3 alerts: question, task complete (threshold), error, aborted, startup, context-window 25/50/75% crossings; model-unaware (pure events) |
| `quick-open-dir.ts` | `/qd` | Open data dir / .pi dir in the OS file manager |
| `response.ts` | `/aftc-response-divider` | Themed divider above each assistant reply |
| `run-script.ts` | `/run-script-on`, `/run-script-off` | `run_script` model tool: reliable large/multi-line script execution (works around a pi bash truncation bug) |
| `debug-log.ts` | `/aftc-debug-log-on`, `/aftc-debug-log-off` | Toggle `debugLoggingEnabled` — the gate on `aftcConsole.log` stdout diagnostics (off by default; errors never gated) |

## Internal architecture & data flow

One factory per module (`createX(pi)`), no cross-imports, state in factory closures. Conventions enforced by tests: help-registry 1:1 with commands (`tests/help-registry-check`), shortcuts only in keys.ts, output via aftc-console, dialogs via aftc-ui with `ctx.hasUI` guards. Alias commands share one handler (stfu/kis/replay pattern).

## Configuration

Per-feature keys in `config.json` (all default sane, new features disabled): `responseDividerEnabled`, `thinkProcessingEnabled`, `notifyEnabled` + `notifySound*` + `notifyTimeSec`, `runScriptEnabled`, `replayPrompt`, `aftc-intro`, `debugLoggingEnabled`.

## Setup, seeding & first run

Nothing per module; `/aftc-install` for the ones needing deps (notify needs no deps — bundled players, 1.11).

## Testing

Per-module suites: `keys-check`, `quick-open-dir-check`, `notify-check`, `intros-check`, `install-check`, `install-platform-uv-check`, `run-script-check`, `bulk-read-check`.

## Operational notes & known limitations

- `run_script` exists only to work around an upstream pi bash-tool truncation bug (reported); disable with `/run-script-off` once pi ships a fix.
- `notify` preview playback kills the previous preview before starting the next (no overlap while browsing).
